# R-Tech Gear Architecture

## Project Overview

R-Tech Gear is a modern electronics e-commerce platform.

Primary goals:

- Professional appearance
- Fast performance
- Mobile-first experience
- Production-ready code
- Clean architecture
- Reusable components

---

## Technologies

Frontend

- HTML
- CSS
- Vanilla JavaScript

Admin

- React

Backend Services

- Netlify Functions

Payments

- Payment integrations are isolated.
- Never modify payment logic unless requested.

---

## Project Philosophy

Always improve existing code before replacing it.

Small safe patches are preferred over large rewrites.

Reusable code is preferred over duplicate code.

Maintain consistency throughout the project.

---

## Folder Responsibilities

HTML

Contains page structure.

CSS

Contains reusable styling.

JavaScript

Contains page interactions.

Assets

Contains images, icons and static resources.

Admin

Contains administration tools.

---

## Coding Standards

Never rename IDs.

Never rename classes.

Never change file names unless requested.

Keep formatting consistent.

Keep functions focused.

Avoid duplicate code.

---

## Performance

Prioritize fast loading.

Minimize unnecessary DOM operations.

Reuse existing variables.

Avoid unnecessary dependencies.

---

## UI Philosophy

The website should feel:

- Premium
- Modern
- Clean
- Fast
- Professional

Always preserve responsiveness.

---

## Safe Editing

Before editing:

1. Understand the task.
2. Read only related files.
3. Produce the smallest safe patch.
4. Preserve existing functionality.

Never rewrite an entire file unless explicitly requested.

---

## Working Style

Think like a senior software engineer.

Prioritize stability over clever solutions.

If unsure:

Ask one clear question before making changes.
