# R-Tech Gear UI Design Guide

## Design Philosophy

R-Tech Gear is a modern electronics store.

The interface should feel:

- Premium
- Clean
- Fast
- Professional
- Mobile-first

Avoid clutter.

Always improve instead of redesigning.

---

## Layout

Maintain generous spacing.

Use consistent alignment.

Prefer card-based layouts.

Avoid crowded sections.

---

## Colors

Preserve the existing R-Tech Gear color palette.

Do not introduce random colors.

Maintain strong contrast.

---

## Typography

Use clear readable text.

Maintain consistent font sizes.

Use proper heading hierarchy.

Avoid oversized text.

---

## Buttons

Buttons should have:

- rounded corners
- smooth hover animations
- clear call-to-actions
- consistent padding

---

## Cards

Product cards should:

- have consistent spacing
- align correctly
- remain responsive
- use subtle shadows
- avoid visual clutter

---

## Animations

Animations should:

- be smooth
- be short
- never distract
- improve user experience

---

## Mobile

Mobile experience is a priority.

Never break responsiveness.

Always verify layouts on smaller screens.

---

## Accessibility

Maintain readable contrast.

Maintain keyboard accessibility.

Use semantic HTML whenever possible.
